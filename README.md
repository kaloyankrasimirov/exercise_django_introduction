# Notes App 📝

A foundational Django web application built to demonstrate core Model-View-Template (MVT) architecture, dynamic query filtering, and real-time JavaScript search debouncing.

---

##  Features

* **Dashboard Overview:** Displays total note counts alongside all created notes.
* **Category Management:** Browse notes organized by custom categories.
* **Real-time Live Search:** Auto-submits search queries on keystroke with JavaScript debouncing while preserving cursor position and input value.
* **PostgreSQL Database:** Powered by PostgreSQL for persistent data management.

---

##  Tech Stack

* **Backend:** Python, Django
* **Database:** PostgreSQL
* **Frontend:** HTML5, Vanilla JavaScript
